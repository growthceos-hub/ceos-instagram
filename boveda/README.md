## Antes de usarlo

- La skill `comenta-palabra-boveda` dice que no se promete un envío hasta que la entrega por privado funcione. En LinkedIn no hay respuesta automática por API para perfiles personales: el envío es a mano (o con una herramienta aparte) hasta que se monte.
- Responder en público a cada comentario («¡Te lo mando por privado!») y mandar el mensaje el mismo día.
